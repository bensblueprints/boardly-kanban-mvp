# boredly tutorial

Connect your ChatGPT account in Account & AI. No OpenAI API key is required when using ChatGPT. Your ChatGPT plan’s Codex access and limits apply.

## Companies, boards and projects

A company keeps work for one business together. Boards group related work, such as Web hosting clients. Projects hold individual assignments, such as a client website.

1. From Companies, choose New company and enter its name.
2. Open the company, choose New board, and name the group of work.
3. Open the board and choose New project. Add a clear description of the outcome you want.
4. Check existing companies and projects before creating another one. Unassigned boards keeps older work available.

## Tasks and checklists

Open a project to see its task lists. A card represents one clear piece of work; its description, checklist, comments and files keep the context together.

1. Add a card to To Do and explain the desired result. Open it to add checklist steps or a due date.
2. Use In Progress while someone is actively working. Move a task to Blocked when it needs input or access, and record the exact next action.
3. Move verified work to Done Awaiting Revisions when that list is available. Drag cards between lists as their status changes.

## Ask, Plan and Work

Open Chat with AI in a company, board or project. Choose the scope that contains the information you want the AI to use.

1. Ask answers questions about the saved work. Try: “What needs my attention in this project?”
2. Plan drafts a proposed approach. Try: “Plan the next three steps for this client.”
3. Work can update project tasks and files and use enabled connections. Give a clear outcome, then review its saved activity and result.
4. Use a separate conversation for a different topic. Independent projects can run concurrently; work in the same project may wait to avoid conflicting changes.
5. Expand the chat window when you need more space. If an assignment is blocked, read its next action, restore the missing access or answer the question, then resume the saved assignment.

## Audio briefings and replies

Audio briefing sits beside Chat with AI in companies, boards and projects. It summarizes the saved work and what needs attention.

1. Choose Audio briefing and start playback. You can also read the briefing on screen.
2. Type your reply, or use the microphone when your browser supports voice input and you grant microphone access.
3. Choose Send question to discuss the briefing, or Start work to turn your reply into an assignment. Review the resulting chat and activity.

## Files, folders and project links

Files keeps the documents and deliverables for the current project together.

1. Open Files and choose New folder to organize related material. Open a folder to work inside it.
2. Upload files, create nested folders and move files to the appropriate folder. Your account storage allowance applies.
3. Add useful project links and explain what they are for. Give the AI a specific file or task to use when requesting work.

## GitHub, SSH and other connections

Account & AI contains your personal AI connection and account connections. Project settings control what a project can use.

1. Connect ChatGPT, approve the code on OpenAI’s website, then use Test ChatGPT connection. No API key is required for this option.
2. Save reusable GitHub and SSH connections in Account & AI, then select and enable the appropriate connection in a company or project.
3. For SSH, test the connection and verify the server identity. Enable only the connections that project needs.
4. Project environment variables, email and other integrations have their own setup and permissions. AI can only perform actions supported by its runtime and enabled tools.

## Team access and account settings

Owners can invite members and choose which companies or projects they can access. Shared work uses the sponsoring owner’s AI connection.

1. Use Members in the relevant company or project to invite someone and select their role and scopes.
2. Viewers can read permitted work. Editors can change permitted work; sensitive integrations have separate permissions.
3. Use the account selector to switch between your own workspace and accounts shared with you. Your personal ChatGPT connection stays with your account.
4. Account & AI shows plan allowances and billing availability. API billing is an optional alternative to ChatGPT; boredly subscriptions and ChatGPT subscriptions are separate.

## Computer use and troubleshooting

The Computer use panel shows requests and availability for the upcoming computer add-on. A request does not mean a computer is ready.

1. The planned computer offer is $29.99 per month for 8 GB RAM and 150 GB storage. Provisioning and checkout must be enabled before computers can be purchased and used.
2. If AI cannot reply, open Account & AI and test your connection. Check ChatGPT usage limits or follow its sign-in instructions.
3. If a server or repository cannot be reached, test that saved connection and inspect the assignment activity before retrying an external change.
4. Use boredly in your browser for the current cloud workspace. Desktop download and sync setup is separate; do not assume an older desktop installation is synchronized.
