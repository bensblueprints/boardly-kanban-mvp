A few things to know.

Do I need a credit card to get started?

No. Create an account and start on Basic Free with one company, one user and 2 GB of storage. You do not need to enter payment details.

Is AI included in the free plan?

Your workspace is free. To run supported project AI tasks, connect your own OpenAI API key; your provider bills its usage separately. Native Codex cloud workers and company-wide orchestration remain in private preview.

Can I use boredly with a team?

boredly supports company and project membership with Editor and Viewer permissions. Basic Free includes one user. Additional seats and larger account plans require an upgrade when paid billing becomes available.

Does the desktop app work offline?

The current desktop experience opens the cloud workspace in its own browser app window and needs an internet connection. Offline sync with the legacy native desktop app is not available.
